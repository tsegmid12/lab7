# BUG-01: Ном нэмэхэд заавал бөглөх талбаруудын шалгалт байхгүй байна

Орчин:  Уншлагын жагсаалт v2.0, curl, Windows 11, 2026-10-21
Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам
1. API ашиглан Гарчиг-ыг хоосон орхиж ном нэмэх:
   `curl -i -X POST http://localhost:3000/api/books -H "Content-Type: application/json" -d '{"title": "", "author": "Test", "year": 2000}'`

Хүлээгдээж байсан: Ном нэмэгдэхгүй, ойлгомжтой алдааны мессеж харагдана (Спецификаци: "Гарчиг, Зохиолч, Он гурван талбар бүгд заавал бөглөгдсөн байх ёстой").
Бодит үр дүн: HTTP 201 Created буцааж, ном амжилттай нэмэгдэв.

Ноцтой байдал: Major - Өгөгдлийн бүрэн бүтэн байдлыг алдагдуулна.
