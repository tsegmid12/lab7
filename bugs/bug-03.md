# BUG-03: API-д буруу бүтэцтэй JSON илгээхэд 400 алдаа буцаахгүй байна

Орчин:  Уншлагын жагсаалт v2.0, curl, Windows 11, 2026-10-21
Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам
1. JSON-ыг хаах хашилт (-) дутуу илгээх:
   `curl -i -X POST http://localhost:3000/api/books -H "Content-Type: application/json" -d '{"title": "Fail", "author": "Fail", "year": 2000'`

Хүлээгдээж байсан: HTTP 400 Bad Request буцаана (Спецификаци: "буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана").
Бодит үр дүн: HTTP 200 OK буцааж, алдааг зөв тодорхойлж чадсангүй.

Ноцтой байдал: Major - API-ийн алдааг зөв удирдаж чадсангүй.
